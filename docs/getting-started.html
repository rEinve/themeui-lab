Getting started

Start small. Use the system in order.

Bring in the shared stylesheet, start the page with layout primitives, then choose the smallest component that owns the interface job.

1. Link a local package

Use it in a consuming project

ThemeUI Lab is currently linked locally while the package evolves. Build the stylesheet before linking it into another project.

# In this repository
npm run build:package
npm link

# In the consuming project
npm link themeui-lab
// In the consuming app entry point
import "themeui-lab/styles.css";
import { initTabs, initCarousels } from "themeui-lab";

2. Build the page before the detail

Start with layout primitives

Primitives own the page structure. Components can then focus on their internal UI without inheriting page-level layout work.

<main>
  <section class="section">
    <div class="container">
      <div class="stack stack--l">
        <h1>Page title</h1>
        <p>Page introduction.</p>
      </div>
    </div>
  </section>
</main>
