What it is

A practical design system, not a bag of styles.

The system keeps repeated decisions in one owned place, so a page can be composed without every feature inventing its own spacing, controls, or layout rules.

It stays intentionally small: use the existing primitive or component when it owns the job; create a new one only when a repeatable need is clear.
